# 3D Viewport Reference Tool

A desktop application for viewing 3D models and recording the viewport.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run locally in development mode:
   ```bash
   npm start
   ```

3. Build production application:
   ```bash
   # Build Windows .exe
   npm run build:win

   # Build macOS .dmg
   npm run build:mac
   ```
